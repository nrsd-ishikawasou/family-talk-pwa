## 本書の位置付け

- ISO/IEC/IEEE 29119-3:2021 の試験データの要件（8.5）と試験環境の要件（8.6）を束ねる。環境の項目ごとに「何に使うか、誰が用意するか、無い時」を書く。

## 2. 試験データ

|番号|データ|作り方・出どころ|使うレベル|上限・注意|
|---|---|---|---|---|
|D-1|模擬の家族（5 人、各 2 端末、10 年分のイベント 10 万件、写真 1 万枚、動画 100 本、投票・ノート・予定・アルバム）|試験のコードが生成（決定的な乱数の種）。本文には固有の語（平文検査用）を埋める|L1・L3・L4・性能|生成ファイルは Git に入れない。個人の情報を含まない|
|D-2|MLS の相互運用の検証ベクトル|公式の相互運用の資料（mls-implementations）から取得の道具が版と SHA-256 つきで置く|L3（T-L3-01）、L0（暗号の部品）|Git に入れない。版を記録|
|D-3|エラーコード表 api/errors.yaml の各事象を起こす入力|行ごとに「起きる条件」から作る。エラーコード表の `test` の欄がその試験|L1|エラーコード表と試験の名前の一致は道具（T-L2-05）|
|D-4|境界の fixtures（経路ごとの要求と応答の見本、イベントの見本、`ft.content.*` の見本）|L1 の試験が書き出す。揺れる欄は固定の値|L2・L3|形の見本。値の意味は L1・L4|
|D-5|写真と動画と音声の形式（JPEG、HEIC、PNG、WebP、巨大（1 億画素超、20 MB 超）、壊れた物、EXIF の向き各種；MP4/H.264、HEVC、4K、HDR、VP9、5 分超、1 GB 超；AAC、Opus、WebM；ファイル：PDF、zip、SVG、HTML、実行可能）|試験のコードが生成（小さい物）と、NRSD の実機で撮った物（HEIC、HEVC、HDR。Git に入れない）|L3・L4・L6|第5章の上限の内外を 1 件ずつ|
|D-6|試行の束（家族の名前と写真の模擬、招待、手順の紙）|担当開発者が用意し、プレビュー版と一緒に渡す|L6 の試行|参加者の写真は使わない|
|D-7|バックアップのリポジトリ（正常、壊した物、古い版のバックアップ、抹消の後のバックアップ）|L1 の T-L1-10 が作る|L1・L4・L6|—|
|D-8|回線の形ごとの設定（.env の例、ルーターの転送の表、MAP-E の範囲の例）|手順書の例|L5（Compose の起動）、L6|—|
|D-9|語表（2048 語）とカードの検証ベクトル（既知の `F` から作った 3 枚の語と検査語）|NRSD（語表。第10章 10）、試験のコード（ベクトル）|L3（T-L3-02）、L6（T-U-06）|語表の実物が無い間は仮の語表（一覧の赤）|
|D-10|文言の表（日本語）と禁止語の一覧（技術の語、他社の名称、痕跡）|第10章 9、第14章 14。禁止語の一覧は Git の外（開発者の手元の記録）|L3（T-L3-07）、L5（T-L5-08）|他社の名称の一覧は公開リポジトリに置かない|
|D-11|脅威の試みの入力（推測の token、cross-site の要求、改竄したイベント、偽の APK とイメージ、SSRF の URL）|試験のコード|L1・L4（T-S）|—|
|D-12|性能のデータ（10 万件、写真 50 枚、4K HEVC 3 分、500 GB のバックアップ）|D-1 と試験のコードが生成|性能|CI は小さい分だけ（上限の 1.5 倍の判定）|

- データの保持：生成ファイルは試験のたびに作り捨てる。Git に置くのは小さい見本（D-4、D-3 の一部）だけ。個人の情報を含むデータは持たない。本文の固有の語は走査の道具だけが知る。
