## S-03a 招待の発行と受け取り（第3章 3.2）

![シーケンス図：S-03a 招待の発行と受け取り（第3章 3.2）（画像を開くと原寸で読める）](../fig/シーケンス図/03_招待と参加_1.png)

<details><summary>図の元の文（mermaid）</summary>

```mermaid
sequenceDiagram
  participant U as 招待する人
  participant UI as web-ui
  participant BD as srv-boundary
  participant ID as srv-identity
  participant AD as srv-admin
  participant V as 招待を受ける人
  U->>UI: 設定 > 端末 or 管理者の画面 > 招待
  UI->>BD: POST /invites {role, display_hint?, child?}（Idempotency-Key）
  BD->>BD: Authz：admin、または設定「構成員も招待を出せる」（子ども区分は MEM-007）
  BD->>ID: Invites::Issue（B-063。同時 20 まで MEM-004）
  BD->>AD: Audit::Record（管理者の発行は監査。B-185）
  BD-->>UI: {id, token, url: /i/<token>, expires_at}
  UI->>U: QR と「リンクを共有」（OS の共有）
  U-->>V: リンク（別の経路）
  V->>UI: /i/<token> を開く（iPhone は Safari、Android は APK の案内の後にアプリ、PC はブラウザ）

  BD->>ID: Invites::Peek（B-063。constant-time + 固定の遅延）
  alt 無効・期限切れ・使用済み
    BD-->>UI: 410 AUTH-007。「招待した人に作り直してもらってください」
  end
  BD-->>UI: {family_name, icon, inviter_name, expires_at, child?: {guardian_names}}（G-12）
  UI->>V: 「参加する」
```

</details>

  UI->>WS: Mls::replenishKeyPackages（B-245）

<details><summary>図の元の文（mermaid）</summary>

```mermaid
sequenceDiagram
  participant WS as web-sync（招待者 or 最初に開いた構成員の端末）
  participant WX as web-crypto
  participant BD as srv-boundary

  WS->>BD: GET /users/{uid}（端末の一覧）の後に POST /users/{uid}/devices/{did}/keypackage

  WSn->>WX: ToDevice::open（B-226）、joinFromWelcome、GroupStore に保存の順

  WSn->>BD: GET /sync（初回）。続けて履歴の同期（S-04d）
  RM->>RM: Timeline::SystemEvent(member_added)「（名前）さんが参加しました」（B-103）。feed で全端末へ
  WSn->>WS: SendQueue::enqueue（family、ft.content.profile/1 の写真）（B-244）
  Note over WSn: 招待者が選んだ他のトークへの追加は、招待者の端末が Members::Add して同じ Commit の流れ
```

</details>
- 失敗：
  - Add を行う端末が途中で切れた：次にオンラインになった構成員の端末が `takeover`（第4章 8）
  - KeyPackage が尽き最後の手段も使えない：端末がオンラインになるまで Add を保留（第12章 13）
  - pending_add が 7 日残る：srv-worker の監視が知らせ（srv-worker.md MonitorHandler）

## S-03e 子ども区分（第3章 9）

- S-03b の画面 2 の後に「保護者：{name}、{name}」を示す。出どころは `GET /invite-tokens/{token}` の応答の `child.guardian_names`（G-12）。
- 画面 6 の明示は子にも分かる文言（P-8 の別の鍵）。

## 抜け

- なし。この入口で見つけた物は直した。
  - G-12：`GET /invite-tokens/{token}` の応答に `child: {guardian_names[]}`（第2章 5.1、srv-identity `Invites::Peek`）
  - G-07：シェルからウェブアプリへの `pushEndpoint` のイベント（第9章 4.2、web-push `Subscription::onShellEndpoint`）
  - G-09：`POST /me/disclosure-ack`（srv-identity `Users::AckDisclosure`）
  - プロフィールの写真の縮小（512×512）：web-media `Photo::prepareAvatar`（512×512 の JPEG、サムネイル 128）
