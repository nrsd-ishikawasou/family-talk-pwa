iPhone の確かめ

このページは家族のサーバーにつながりません。名前や写真などの個人の情報は扱いません。実機の手順は同じ場所の README.md にあります。結果は最後の「結果をコピー」で写して送ってください。

0. 環境

1. WebCrypto（開くと自動で走る）

2. IndexedDB に置いた取り出せない鍵（開くと自動で走る。開き直すと前の鍵を読む）

3. パスキー

「パスキーを作る」の後に「パスキーで入る」を押します。顔か指紋の確かめが出ます。

4. 表示の形

実機の測り（ホーム画面に追加して、アイコンから開く）

(a) 端末の鍵の読み出し（復元の前と後）

復元の前に「端末の鍵を作る」を押します。復元の後に開くと、下の表に開いた時の状態（none、ok、unreadable）が出ます。unreadable なら「消して作り直す」を押します。

(b) 画面のロック中の通知（送る側は開発機）

先に (a) の「端末の鍵を作る」と、下の「通知を許可して購読」を済ませます。通知の本文に「本文を復号できた」と出れば、ロック中に鍵を読めています。

(c) パスキーの PRF

3 で「パスキーを作る」を済ませてから、「PRF を取る」を 3 回押します。3 回とも同じ値なら可です。

(d) 通知の形とバッジ、(e) 着信の通知

送信の道具が出した VAPID の公開鍵を入れて「通知を許可して購読」を押し、出てきた購読の JSON を「購読をコピー」で開発機へ送ります。

(f) カメラとマイク

(g) サイトのデータを消した後

開くたびに 1 行が増えます。設定でサイトのデータを消した後に開くと fresh が true になります。
