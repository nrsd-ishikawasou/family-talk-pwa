# family-talk-pwa

家族専用の通信アプリです。家族は、外部の事業者に連絡の内容を預けずに、日常の連絡を取り合えます。使い勝手は一般的な通信アプリと同じで、文字と写真と動画と通話を使えます（[設計計画書](docs/jp/設計計画書.md) 第2章）。

- 家族のサーバー：家族の誰か（管理者）が、Ubuntu の上の Docker で動かします。管理者向けの画面を持ちます。
- 構成員の端末：iPhone のホーム画面のウェブアプリ、Android のアプリ、PC のブラウザで使います。

## 今の段階

設計を終え、実装を始めた段階です。境界の正本（[api/](api/)）と、その照合の試験（[tools/tests/](tools/tests/)）があります。サーバー、ウェブアプリ、Android のアプリはまだありません。配布物もありません。設置の手順書と、配布物とその検証の手順は、初版の公開の時に載せます。

## できること

- トーク：1 対 1、グループ、家族全員のトーク、自分用メモ。文字、スタンプ、写真、動画、ファイル、音声、位置、連絡先、返信、編集、送信の取消、リアクション、既読、入力中の表示、予約送信、アナウンス、ノート、予定、投票、アルバム（[基本設計書 第4章](docs/jp/design/04_基本設計書_トークとメッセージ.md)、[第5章](docs/jp/design/05_基本設計書_メディア.md)）。
- 通話：音声とビデオ、1 対 1 とグループ（[第6章](docs/jp/design/06_基本設計書_通話.md)）。
- 通知：メッセージと着信（[第7章](docs/jp/design/07_基本設計書_通知.md)）。
- 端から端の暗号化：メッセージ、写真、動画、通話の中身は端末の間で暗号化され、家族のサーバーの管理者も読めません。検索は端末の中で行います（[第12章](docs/jp/design/12_基本設計書_データと暗号化.md)）。
- 家族の管理：招待、端末の追加と取り消し、子ども区分と保護者、バックアップ、更新（[第3章](docs/jp/design/03_基本設計書_認証_構成員_端末.md)、[第11章](docs/jp/design/11_基本設計書_運用.md)）。

## できないこと

- 家族の外の人とのやり取り。招待された構成員だけが使えます。
- 緊急通報（110・119）。本ソフトウェアは電話ではありません。
- iPhone の主な制約（[第8章 4](docs/jp/design/08_基本設計書_iPhoneとPCのシェル.md)）：着信は鳴り続けず、通知で知らせます。ロック中の通話は切れることがあります。通知の音は選べません。通知から返信できません。画面の共有は見る側だけです。
- Android と iPhone での画面の共有（見る側だけ。PC は共有できます）。

## 対応する端末と最低要件

|端末|最低要件|
|---|---|
|iPhone|iOS 18 以上（Safari でホーム画面に追加したウェブアプリ）|
|Android|Android 10 以上を推奨。Android 8.0〜9 は WebView 138 の範囲で動かします|
|PC|Chromium 系、Firefox、Safari の各最新 2 版|
|家族のサーバー|Ubuntu と Docker（[第11章](docs/jp/design/11_基本設計書_運用.md)、[第14章 4](docs/jp/design/14_基本設計書_開発基盤.md)）|

## 情報の扱い

NRSD は利用者の情報を収集しません。家族のやり取りは、家族のサーバーと構成員の端末にだけ置かれます。家族のサーバーが更新を確かめる時は、公開リポジトリの運営者の設備へのアクセスとなり、運営者の方針に従います。

## 免責

本ソフトウェアは現状有姿で提供され、NRSD は法令で許されない範囲を除き一切の保証をしません。本ソフトウェアは電話ではなく、緊急通報（110・119）には使えません。家族のサーバーの運用とバックアップは管理者の責任です。

## 受け口

- 不具合と要望：Issues。家族の情報（名前、写真、やり取りの中身）を書かないでください。
- 脆弱性：[SECURITY.md](SECURITY.md) の手順で、Issues ではなく非公開の報告をしてください。
- 配慮の申出（障害のある構成員への配慮）：電子メールの宛先は、初版の公開の前に載せます。

## 名称の扱い

本リポジトリは、他社の製品とサービスの名称を記載しません。例外は、標準規格とその団体、採用して同梱・依存する部品、前提の基盤（Ubuntu、Docker、iPhone と iOS、Android、GitHub）です（基本設計書 第14章 14）。
