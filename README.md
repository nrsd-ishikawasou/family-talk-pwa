# family-talk-pwa

家族専用の通信アプリです。家族が、外部の事業者に連絡の内容を預けることなく、一般的な通信アプリと同じ使い勝手で、文字、写真、動画および通話により、日常の連絡を取り合えるようにします（[設計計画書](docs/jp/設計計画書.md) 第2章）。

- 家族のサーバー：Ubuntu の上の Docker で動かします。管理者向けの画面を持ちます。
- 構成員の端末：iPhone のホーム画面のウェブアプリ、Android のアプリ、PC のブラウザで使います。

## 今の段階

設計の段階です。ソースコードはまだありません。配布物もありません。設計書がすべてそろった後に、ブロックごとに実装します。
